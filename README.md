# 틈청주 (Gap Cheongju)

이른 체크아웃 뒤 짐 때문에 관광을 일찍 끝내는 청주 방문객에게, 남은 시간·출발지·관심 분야·날씨·관광 수요 근거를 결합해 들를 장소와 이동 순서를 추천하는 시제품입니다.

## 구성

- `index.html`: 청주시 전체 지도와 장소별 관광 수요를 보여주는 최종 시제품
- `server.py`: 카카오 주소 검색·좌표 변환, 날씨, 네이버 온라인 관심도 API를 키 노출 없이 중계하는 로컬 서버
- `run_local.cmd`: Windows용 실행 파일
- `.env.example`: 필요한 환경변수 이름만 담은 예시

## 실행

1. Python 3을 설치합니다.
2. `KAKAO_REST_API_KEY`를 환경변수로 설정합니다. 네이버 검색 API를 사용할 경우 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`도 설정합니다.
3. Windows에서는 `run_local.cmd`를 실행하거나 터미널에서 `python server.py`를 실행합니다.
4. 브라우저에서 `http://127.0.0.1:8767/`을 엽니다.

실제 API 키는 HTML과 저장소에 넣지 않습니다. `.Renviron.kakao`, `.Renviron.naver`, `.env` 파일은 Git에서 제외됩니다.

## 데이터와 해석 원칙

수요의 1차 근거는 한국관광공사 관광 데이터랩 CSV와 지역별 관광 다양성 API입니다. 장소 단위 관광 수요, 방문 흐름, 관광소비 및 내·외국인 구분 자료를 결합하고, 네이버 검색 API 값은 같은 근거등급 후보 안에서 온라인 관심도를 보조하는 용도로만 사용합니다. 네이버 값은 리뷰 수나 별점이 아닙니다.

외국인 지표는 지역별 카드지출 비중을 사용한 프록시이므로 외국인 방문자 수 또는 개인의 국적·성별을 뜻하지 않습니다. 화면의 A/B/C는 관광공사 데이터 근거등급이며, C 후보는 공식 관광자원 존재만 확인된 탐색 대상으로 추천 경로에서 제외합니다.

## 배포 주의

`index.html`만 정적 호스팅하면 지도와 내장 데이터 화면은 볼 수 있지만 `/api/*` 기능은 동작하지 않습니다. Cloudflare Pages 등에 공개할 때는 `server.py`의 중계 기능을 Pages Functions/Workers로 옮기고 API 키를 배포 플랫폼의 Secret으로 설정해야 합니다. 키를 JavaScript나 GitHub 커밋에 넣지 마세요.

## 라이선스와 출처

공모전 분석 결과물입니다. 원자료의 이용 조건과 출처 표시는 한국관광공사 관광 데이터랩 및 각 API 제공기관의 정책을 따릅니다.
